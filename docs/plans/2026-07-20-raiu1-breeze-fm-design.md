# RAIU-1 "Breeze FM" 詳細設計書

作成日: 2026-07-20
状態: **確定**（2026-07-20 レビュー承認済み）

## 1. コンセプトと全体像 ✅（会話で提示済み）

「呼吸する FM シンセ」。DX7 系のキラキラした FM サウンドの中に、風・水・鳥・虫・雨と
いった環境音のテクスチャが溶け込み、弾いた音程に寄り添って揺らめく。エレピを弾くと
遠くで鳥が鳴き、ベースを弾くと地面を雨が打つ楽器。

- C++ / JUCE 8 / CMake、Apple Silicon ネイティブ、AU + VST3
- 2 層エンジン: **FM コア**（4 オペレーター）+ **テクスチャレイヤー**（プロシージャル環境音）
- 2 層は相互作用する（Breath ノブ、ベロシティ連動）
- 内蔵エフェクト: コーラス + リバーブ

## 2. FM コア ✅

- 4 オペレーター FM。各オペレーターは正弦波 + フィードバック
- アルゴリズム 8 種（直列 4 段、並列キャリア、2×2 スタック等。
  エレピ系・ベース系・ベル系・パッド系をカバーする選定）
- オペレーターごとのパラメーター:
  - Ratio（周波数比、0.5〜16、微調整 Detune 付き）
  - Fixed モード（音程無視の固定周波数。ベル・ノイズ的音色用）
  - Output Level / ベロシティ感度
  - ADSR エンベロープ（DX7 の 8 段より簡素だが実用十分）
  - Key Scaling（高音域でレベルを絞る。エレピの自然な明るさ変化に必須）
- ピッチ: グローバル LFO によるビブラート、ピッチベンド、ポルタメント
  （サイレン的な滑らかな音程移動もここでカバー）
- ポリフォニー 16 ボイス、ボイススチール付き。モノモード（ベース用）あり

## 3. テクスチャレイヤー ✅

サンプル不使用。すべて計算によるプロシージャル合成で 5 種のジェネレーターを持つ:

| ジェネレーター | 合成方式 |
|---|---|
| 風 Wind | フィルターノイズ + 超低速ランダム変調（葉ずれの高域含む） |
| 水 Water | 泡状の共鳴バンドパスノイズ（せせらぎ〜水滴） |
| 鳥 Birds | ランダムタイミングのチャープ（周波数スイープする正弦波） |
| 虫 Insects | 高域のパルストレイン群（鈴虫・コオロギ的リズム） |
| 雨 Rain | 粒状インパルスノイズ + ローパス（近い雨〜遠い雨） |

- 各ジェネレーターに Level ノブ。ミックスして 1 本のテクスチャバスへ
- **キートラッキング共鳴フィルターバンク**: 押鍵中の音程に同調した共鳴フィルターに
  テクスチャを通す。これにより環境音が「BGM」ではなく「音色の一部」として鳴る
- Distance ノブ: ローパス + リバーブセンドで「遠さ」を一括操作
- Resonance Mix: 素のテクスチャ ↔ 共鳴後テクスチャのバランス

## 3.5 NATURE OSC — 自然音の音素レイヤー（2026-07-20 ユーザーフィードバックで追加）

グローバルな環境音（§3）とは別に、**自然音を音素として鍵盤で演奏する**ボイス内蔵
オシレーター。「自然音の音程が鍵盤で変わらないのでは新しいシンセとは言えない」との
指摘を受けて設計。

- ボイスごとに内蔵。モード5種: Wind（風笛）/ Water（音程付きの泡）/
  Birds（音階のさえずり）/ Insects（音程キャリアの虫）/ Rain（調律された雨粒）
- **KeyTrack** ノブ: 1.0=完全音階追従、0=固定音程、中間可。Pitch（半音オフセット±24）付き
- **専用 ADSR**（A/D/S/R ノブ）で自然音の立ち上がり・減衰を造形
- **専用レゾナンスローパスフィルター**（Cutoff / Res ノブ）
- **Level** ノブで FM コアとボイス内ミックス — 同じ鍵盤・同じ音程で FM と自然音が重なる

## 4. 2層の相互作用 ✅

ここが「これまでにない音」の核心。

- **Breath ノブ**: テクスチャ音量のエンベロープフォロワーが FM モジュレーターの
  レベルを微変調 → 風が吹くと音色がわずかに開く「呼吸」
- **ベロシティ → テクスチャ**: 強く弾くとテクスチャが開く（量は調整可能）
- **Note On トリガー**: 打鍵の瞬間にテクスチャがふわっと持ち上がる（Swell、量調整可）

## 5. エフェクトとグローバル ✅

- コーラス: 80 年代 BBD 風ステレオコーラス（ラバーズレゲエのエレピに必須）
- リバーブ: プレート系。Distance ノブと連動
- マスター: ボリューム、簡易リミッター（クリップ保護）

## 6. パラメーター管理・プリセット ✅

- JUCE AudioProcessorValueTreeState で全パラメーターを管理（Logic のオートメーション対応）
- ファクトリープリセット（2026-07-20 ユーザー要望により10個に拡張）:
  1. Lovers Keys — 80s ラバーズレゲエ風 DX7 キーボード（ふわキラ + コーラス）
  2. Rub-a-Dub Bass — 太い FM ベース（モノ）
  3. Glass EP — Rhodes 風エレピ
  4. Vibraphone — ビブラフォン風（トレモロ付き）
  5. Music Box — オルゴール風の澄んだ高音
  6. Pure Sine — SINE 波の丸い音
  7. Forest EP — エレピ + 鳥・風テクスチャ
  8. Rainy Bass — ベース + 雨テクスチャ
  9. Thunder Pad — 遠雷パッド（パッド + 風・低域）
  10. Siren Lead — ポルタメントの効いたサイレン風リード

## 7. UI 方針 ✅

段階方式。第 1 段階はシンプルな操作画面（グループ分けしたノブ・スライダー）で音を
最優先。音が固まったら第 2 段階でカスタム UI を作り込む。

## 8. テスト・検証 ✅

- DSP ユニットテスト（エンベロープ形状、周波数、無音時の出力ゼロ等）を TDD で
- auval（Apple 公式 AU 検証）通過を必須条件に
- pluginval によるストレステスト
- Logic Pro 実機での動作確認（発音、オートメーション、プリセット保存）
